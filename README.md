# FrameInterpolation
Change-Aware Frame Interpolation for Robust Indoor Camera Relocalization

This repo contains data and code used for the manuscript "Change-Aware Frame Interpolation for Robust Indoor Camera Localization". 


How to Run: 
1. Install OpenCV using this command pip install opencv-python
2. Download the whole folder with the Jupyter Notebook and the data.
3. Open the Notebook in your Jupyter environment.
